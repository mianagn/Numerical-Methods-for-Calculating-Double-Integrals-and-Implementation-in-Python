## Παράδειγμα χρήσης

```python
import sys
sys.path.insert(0, "code")

import numpy as np
from simpsons_rule import SimpsonsRule1D, SimpsonsRule2D
from quadrature_methods import GaussianQuadrature

# Απλό ολοκλήρωμα: ∫₀² x² dx = 8/3
print(SimpsonsRule1D.composite(lambda x: x**2, 0, 2, n=10))

# Διπλό ολοκλήρωμα: ∫∫[-1,1]² e^(-(x²+y²)) dA
f = lambda x, y: np.exp(-(x**2 + y**2))
print(GaussianQuadrature.integrate_2d(f, -1, 1, -1, 1, n=5))
```

## Σημειώσεις

- Ο κώδικας των μεθόδων στηρίζεται **μόνο στη NumPy**. Η SciPy χρησιμοποιείται
  αποκλειστικά για επαλήθευση και η Matplotlib μόνο για τα γραφήματα της
  εργασίας.
- Η ολοκλήρωση Gauss δέχεται `n` από 1 έως 5 κόμβους. Ο περιορισμός είναι
  συνειδητός και εξηγείται στο Κεφάλαιο 6 της εργασίας.
- Ο σύνθετος κανόνας Simpson απαιτεί άρτιο πλήθος υποδιαστημάτων· αν δοθεί
  περιττό, αυξάνεται αυτόματα κατά ένα.
- Ο προσαρμοστικός Simpson χρησιμοποιεί παράμετρο `min_depth` που αποτρέπει
  πρόωρο τερματισμό σε συναρτήσεις με στενή κορυφή. Το ζήτημα αναλύεται στο
  Κεφάλαιο 9 της εργασίας.
